# 管理界面三语支持

2026-10-08：通用界面支持英语、简体中文、日语，默认英语，浏览器保存语言选择。
本次只涉及 skygo-admin；私有业务扩展不在翻译范围内。

- 登录、初始化、导航、主机、服务、任务、配置、审计、管理员、构建、发布、镜像分发及通用数据控件使用统一字典。
- 缺失翻译回退英语；未知错误保留原文。动态句子使用命名参数，不翻译业务数据或凭据。
- 状态计算返回稳定标识，展示阶段才翻译；不改变审批、签名、权限和任务重试协议。
- 请求或弹窗未结束时禁用语言切换，未提交表单须确认放弃；保留路由和已有发布申请标识。
- 扩展接口与兼容边界见 [扩展说明](extensions.md#前端语言接口)。

## 验证入口

`make web-test` 包含字典完整性、参数一致性、默认语言、偏好恢复、存储失败、
缺失翻译回退、静态文案以及未提交表单检测；原有审批和状态测试继续执行。

浏览器回归脚本为 `scripts/test-web-locales.cjs`。脚本仅拦截并返回模拟 API 数据，
不接触真实管理员、数据库或 Agent，结束后关闭浏览器。Playwright 是可选测试工具，
无需添加到项目运行依赖；安装在独立临时目录后，通过 `NODE_PATH` 指定其
`node_modules` 位置。已安装的 Chromium 可通过 `SKYGO_TEST_CHROMIUM` 指定：

```sh
NODE_PATH=/path/to/test-tools/node_modules node scripts/test-web-locales.cjs
```

默认截图输出到独立临时目录，也可用 `SKYGO_LOCALE_ARTIFACTS` 指定输出目录。
脚本验证三语登录、全部通用导航、原始数据保留、放弃修改确认、请求和弹窗锁定、
设置页恢复、切换不重复提交，以及窄屏可用性。模拟 API 的浏览器验收不代表实际部署验收。
