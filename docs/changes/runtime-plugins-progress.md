## 已实现

- plugin 包：本机 Unix Socket HTTP/JSON 通信、协议和不可变 revision 校验、有限请求/响应、拒绝跳转与自动重试。
- 插件端请求分派接口；清单 Ed25519 验签、独立信任公钥、能力授权交集及资源摘要验证工具。
- Agent plugins 配置绑定本地服务和扩展动作；插件不可用拒绝本地受保护操作，不影响未绑定服务。
- ADMIN_PLUGINS_CONFIG 加载动作验证器；不在启动时写权限表。
- 签名任务和观察增加可选 plugin_revision，旧的无插件指令保持兼容。已完成回执可重放；未完成任务遇到版本变化保持不确定。
