# v0.3.1 — complete API-served frontend assets

Use v0.3.1 for the workflow release. It includes the v0.3.0 schema v5 and
workflow APIs and fixes the API static-resource allowlist to serve locale.js
for both embedded and filesystem frontends. Remote container integration found
the missing route in v0.3.0; separate web images already contained the file.

The full standalone Docker/Skygo smoke test checks every HTML script and CSS
reference through both API and web origins, plus 404 behavior for missing files.
